# English Cards

Android-додаток для вивчення англійських слів картками (Kotlin + Jetpack Compose).

## Як встановити на телефон

1. Відкрийте [останній реліз](https://github.com/Fraid-122/english-cards/releases/latest).
2. Завантажте `english-cards.apk`.
3. Відкрийте файл і дозвольте встановлення з цього джерела.

APK збирається автоматично через GitHub Actions після кожного пушу. Усі збірки підписані одним ключем, тому нова версія встановлюється поверх старої, і картки не зникають.

## Що вже є (етап 1)

- Головний екран: скільки карток треба вивчити і скільки вже знаю.
- Додавання, редагування, видалення і пошук карток.
- Екран «Теми та складність»: картки, зібрані за темою і за складністю.
- Навчання: свайп вправо — знаю (зелений), вліво — не знаю (червоний).
- Можна вписати слово по буквах: правильне слово саме переносить картку вправо.
- Кожна картка зберігається окремим JSON-файлом у пам'яті додатка на телефоні.

## Автопереклад і ШІ (етап 2)

- Переклад працює офлайн через Google ML Kit: без ключа і без лімітів. Мовний пакет завантажується один раз.
- Англійське слово перекладається українською, українське — англійською.
- Якщо змінити чи стерти слово, усе згенероване стирається і створюється заново.
- ШІ (необов'язково) підбирає картинку-емодзі, тему, складність і приклад речення. Він працює через безкоштовний API-ключ Google Gemini: головний екран → «Увімкнути ШІ (картинки й теми)».
- Ключ зберігається лише на телефоні, у репозиторій він не потрапляє.

## Далі за планом

- Етап 3: YouTube (відео із субтитрами, слово чи фраза одразу в картку).

## Для розробки

- Збірка: `./gradlew assembleDebug`, тести: `./gradlew testDebugUnitTest`.
- `keystore/debug.keystore` — це лише тестовий ключ підпису для debug-збірок, не секрет.
- Справжні секрети (API-ключі) у репозиторій не кладемо.
